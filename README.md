# SmartStockAI v3.6.1
修正 v3.5/v3.6 行情資料無法跨版本可靠保存的問題。

原因：v3.5 把每月行情主要放在 localStorage；50×36 月資料可能超過手機瀏覽器 localStorage 容量，寫入失敗會被程式忽略，因此當次記憶體內可以完成 1800/1800 與驗證，但換版/重載後可能只剩 0/1800。

v3.6.1 改用 IndexedDB `SmartStockAI_MarketData/months` 永久保存每個「股票×月份」行情。
- 啟動時先讀 IndexedDB
- 若舊 localStorage 還有資料，自動搬進 IndexedDB
- 新下載每成功一個月份立即寫入 IndexedDB
- 未來版本只要維持同一網站來源與資料庫名稱，即可直接沿用
- v3.6 風控比較功能保留

若手機目前已沒有 v3.5 的原始行情資料，歷史資料無法從舊的完成數字反推，這次仍需重新下載一次；但完成後不應再因單純升版而重抓。
