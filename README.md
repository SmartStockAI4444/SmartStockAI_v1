# SmartStockAI v4.3 — 紙上交易管理與停損歷史補查

以 v4.2 為基礎，保留 `localStorage.ssa39paper`、既有兩組紙上帳戶、持股、現金、交易紀錄與 IndexedDB 行情資料。

- 新增「補查停損歷史資料（不改交易）」：只檢查手機已保存的官方歷史收盤資料，嘗試補回舊停損事件缺少的觸發日、觸發收盤與跌幅。
- 只會補上有歷史資料支持的欄位；不改寫成交日／成交價，不新增假交易，也不把「找不到」當成「未觸發」。
- 若本機資料不足，會明確保留「歷史資料缺失／待確認」狀態。此按鈕不會另外下載行情。
- 固定 -10% 停損規則不變；收盤觸發後，仍以可取得的下一交易日官方開盤價作為模擬成交價，跳空可能造成超過 10% 的損失。
- 版本更新只改頁面版本與快取識別；不清除紙上帳戶或歷史行情。

## Android 部署
1. 解壓縮 ZIP。
2. 到 GitHub `SmartStockAI_v1` 儲存庫首頁，點 `...` → Upload files。
3. 上傳並覆蓋 ZIP 內全部 6 個檔案。
4. 開啟網站並重新整理，確認頁首顯示 v4.3。
5. 在「未來紙上模擬交易」區，先按「匯出紙上帳戶備份 JSON」保存一份，再按「補查停損歷史資料（不改交易）」。

研究用途；不連接券商、不會真實下單，歷史結果不保證未來績效。
