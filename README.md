# SmartStockAI v3.8.1
修正 v3.8 第五步 0 筆交易問題。

原因：TWSE 歷史資料日期可能使用民國年格式（例如 115/10/02），而第五步投資組合時間軸與樣本外訊號日期沒有統一格式，造成訊號無法與行情日匹配。

修正：
- 所有第五步日期先正規化成 YYYY-MM-DD。
- 民國年自動 +1911。
- 保留 IndexedDB SmartStockAI_MarketData/months，無需重抓 1800 份行情。
- 額外顯示「訊號數 / 實際買進數 / 行情日數」，方便立即確認模擬器有真正成交。
- 策略參數完全不變：Strategy >=65、持有20日、成本0.585%、最多5檔、NT$100,000、比較無停損與固定 -10%。
