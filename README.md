# SmartStockAI v4.0 — 紙上交易管理

沿用 v3.9.4：50檔×36月歷史行情、IndexedDB `SmartStockAI_MarketData/months`、`localStorage.ssa39paper` 虛擬帳戶。不需重新下載1800份，不清除已存在持股或帳戶資金。

- 第六步新增雙帳戶持股明細、現金/市值/資產、未實現損益、買賣紀錄與資產折線圖。
- 新增手動匯出/匯入 JSON 備份；匯入前會確認覆蓋。
- 保留 v3.9.4 當天以收盤價模擬買進的既有5檔持股，標示為「承接」。**不追溯變更**。
- 自 v4.0 後產生的收盤訊號，僅排入下一交易日候選，於下一交易日以台灣證交所官方**開盤價**假設買進；停損/期滿亦在收盤後觸發並排入下一交易日開盤賣出。
- 如果無法取得官方開盤價，跳過假設成交。不在當天收盤後以當天收盤價補買。
- 維持最多同時5檔、Strategy≥65、最多20交易日、收盤 -10% 風控對照；相同交易日只更新一次。
- 為延續原帳戶，**費用沿用 v3.9.4 每次成交收 0.585%**；意即完整來回約1.17%，這與歷史回測「往返0.585%」並不相同。顯示費率真相、避免暗中變更現有帳戶。
- 如遇漏掉交易日，暫停自動處理，避免把未曾在當天確認的交易偽裝成真實前瞻成交。
- 紙上帳戶只存在這台裝置的瀏覽器儲存空間。建議每週匯出備份檔。

此為研究用途；不連接券商，不會真實下單，不保證未來績效。
