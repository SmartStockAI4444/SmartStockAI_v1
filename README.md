# SmartStockAI v3.8 — 資金型投資組合驗證

沿用 v3.6.1 起的 IndexedDB `SmartStockAI_MarketData/months`，正常情況不需重抓 1800 份行情。

基準策略不變：
- Strategy >= 65
- 持有最多 20 個交易日
- 簡化交易成本沿用 0.585%
- 50 檔、36 個月、70/30 樣本外架構

新增第五步：
- 初始資金 NT$100,000
- 最多同時 5 檔
- 每檔目標約總資產 20%
- 同日訊號依 Strategy 分數排序
- 逐交易日處理持倉重疊與資金占用
- 比較「無停損」與事先固定「-10% 收盤停損」
- 顯示期末資金、總報酬、最大回撤、交易數、勝率與停損次數

注意：仍為研究用歷史模擬，不含盤中成交、滑價、零股細節、股利與完整實際稅費。
