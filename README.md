# SmartStockAI v3.7 — 風控穩健性驗證

沿用 v3.6.1 的 IndexedDB `SmartStockAI_MarketData/months`，正常情況下 1800 個「股票×月份」行情不必重新下載。

基準策略鎖定：
- Strategy >= 65
- 持有 20 個交易日
- 簡化往返成本 0.585%
- 前 70% 形成期 / 後 30% 樣本外

v3.7 新增預先固定的風控比較：
- -8% / -10% / -12% / -15% 收盤停損
- 每個訊號日最多 5 檔，依原 Strategy 分數排序
- 同時顯示勝率、平均報酬、停損次數
- 新增「日期型等權投資組合淨值」最大回撤估算
- 保留簡化交易序列 DD 作參考

目的不是挑最高報酬參數，而是看不同合理風控強度下，正期望與回撤改善是否具有一致性。

限制：日期型淨值仍是研究用近似值，尚未完整處理重疊持倉、資金占用、盤中成交、滑價、股利與實際交易細節。
