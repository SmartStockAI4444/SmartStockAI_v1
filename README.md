# SmartStockAI v1

手機優先的台股 AI 選股與模擬交易 PWA 第一版。

## 已完成
- NT$100,000 模擬本金
- 今日 AI 精選最多 5 檔
- 模擬買進 / 賣出
- 模擬持股
- 交易紀錄
- 績效統計
- Strategy v1.0 說明
- localStorage 本機保存
- PWA / Service Worker 離線基本支援

## 重要
目前股票、價格與 AI 分數全部是固定「示範資料」，不是即時行情，也不是投資建議。此版目的為驗證 UI 與模擬交易流程。

## 執行
直接以靜態網站伺服器開啟即可。部署至 GitHub Pages 時可直接使用根目錄。
