# SmartStockAI v3.6

以 v3.5 已成功的 50 檔 × 36 月核心直接修改。

固定基準策略不變：
- Strategy >= 65
- 持有 20 個交易日
- 每筆簡化往返成本 0.585%
- 前 70% 形成期、後 30% 樣本外

新增第四步風險控制對照：
- 同一訊號日最多持有 5 檔，依 Strategy 分數由高到低
- 模擬 -10% 收盤停損
- 並排顯示原策略與風控策略的交易數、勝率、平均報酬、簡化最大回撤
- 顯示停損觸發數與風控後前 5 股報酬貢獻度

沿用 ssa35_ / ssa33_ 行情快取，因此同一瀏覽器正常情況下不必重抓 1800 筆資料。

注意：回撤與停損仍為簡化歷史模擬，不等於真實帳戶淨值或成交結果。
